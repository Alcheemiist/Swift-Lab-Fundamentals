# Swift Lab Fundamentals

My work through Apple's [*Develop in Swift Fundamentals*](https://books.apple.com/us/book/develop-in-swift-fundamentals/id1511184145) course: Swift language playgrounds plus small UIKit apps.

| Folder | Contents |
|---|---|
| [`Unit1`](Unit1) | Playgrounds for constants & variables, operators and control flow · Interface Builder basics · first debugging session |
| [`Unit2`](Unit2) | Playgrounds for strings, functions, structures, classes, collections and loops |
| [`TicTacToe`](TicTacToe) | A UIKit Tic-Tac-Toe game |
| [`2.7 UIKit Survey`](2.7%20UIKit%20Survey) | A tour of the core UIKit controls |
| [`UIKitTestPlayGround`](UIKitTestPlayGround) | UIKit sandbox |

Open any `.playground` or `.xcodeproj` in Xcode to run it.
